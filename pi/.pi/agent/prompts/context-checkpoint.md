---
description: Record a compact durable checkpoint before compaction or a session handoff
argument-hint: "[work-item path or focus]"
---
Load the work-context skill and checkpoint the current task in its existing notes
(defaulting to `~/work-context/tasks/<stable-id>/` when no workspace-specific notes
root overrides it). Focus: ${@:-the current approved task}. Read the notes before
targeted edits. Preserve the goal, scope, decisions, exact checkout/branch/revision,
changes, checks, blockers, next action, and approval boundary. Link evidence rather
than copying logs. If the work item is still ambiguous, ask rather than inventing
one. Do not compact, restart, publish, or contact another session automatically.
